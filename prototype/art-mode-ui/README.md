# PROTOTYPE (throwaway): Art Mode UI

Question: what should Domindle's Art Mode look and feel like?

Open `index.html` (art/ is alongside). Variants A, B, C, D, E switch with ← / →.

**Verdict:** variant E (card frame on a dark table, art as a real Dominion card) with the 📊 Stats button opening a modal (from B), 9 zoom-out steps, "even" (geometric) easing. A was liked structurally but its style was not; D (flat paper) was the lighter alternative.
